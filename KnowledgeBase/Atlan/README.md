# Atlan — GTM work sample & builds

This is Manan Aggrawal's working knowledge base for the Atlan Agent Registry GTM challenge ("find the first 100 teams") and this Doorway deployment. It reflects **current state**, not the full research history — superseded drafts and raw research rounds are intentionally left out.

## Map

- `Strategy/` — the locked ICP, research findings, GTM problem catalog, channel plan, path-to-100 funnel math, the decision deck, and background on Atlan's own Agent Registry product.
- `Challenge/` — the original brief and the submission assembly plan.
- `Product-Doorway/` — this deployment itself: Atlan Doorway, a self-hosted knowledge-base/skills/tools platform.

## The one-paragraph version

Atlan asked for one ICP, one distribution channel defended with evidence, and a working artifact — not a strategy deck. The locked ICP is the solo builder or very small team who has published their own Claude Skills as a public GitHub repo (for reasons unrelated to Atlan — audience, credibility, teaching) and now has forks and strangers depending on a repo they maintain alone. The wedge is an audit/health tool ("share the score, never the skill") distributed through GitHub-native channels and Reddit's r/claudeskills — the skills-marketplace shelf itself is already crowded. Atlan Doorway is this GTM effort's own knowledge base, standing up the skills, tools, and strategy artifacts produced along the way.
