## The four things worth knowing, if you read nothing else

1. **The sharing pain is documented and Anthropic declined to fix it.** `anthropics/claude-code#28327` asks for team skill sharing, has two issues closed as duplicates of it, and is itself closed `not_planned`. The reported friction threshold is ~5 engineers, not 50.
2. **The wedge is not unclaimed.** A dozen products are already on it — shareskills.ai published a manifesto the same day we searched. Differentiation cannot be storage; it has to be the evidence layer AWS explicitly deferred and Atlan already demos.
3. **The do-nothing case is real.** "A git repo plus Anthropic's native plugin marketplace, assembled DIY," defended by credible engineers. Plus a sharper conditional objection from Reddit, and one obstacle nobody else surfaced: a 99-upvote comment arguing against sharing skills at all, on job-security grounds.
4. **Nobody has published how many skills a typical team has.** The number that decides every ICP threshold in this market does not exist. That absence is the opening.
