# 3 — Evidence appendix

## `evidence_brief.html`
The research summary, as a single self-contained page. Open it in any browser — no build step, no assets, no network needed beyond web fonts.

Also published as a live artifact: https://claude.ai/code/artifact/487da8fe-37d4-452b-bea2-a9ef57a6f721

**What it covers** (eleven sections, ~10 minutes to read):
1. The bet — ICP, channel, activation definition, and the storage→evidence reframe
2. Four findings, in the B1–B4 buckets the raw research was sorted into
3. Hypothesis ledger — all ten, with kill criteria and status (H5 killed, H4 weakened)
4. The crowded field — the competitors that killed H5
5. The missing skills-per-team number, treated as an asset
6. Verified numbers, plus the two corrections the verification pass caught against our own case
7. Channel read and launch sequencing
8. The three prospect tiers, with the sunk-cost risk named
9. Rejected alternatives, each with its strongest honest case
10. What's still open, and the continue / change / stop signals
11. How the research was run

**Sources.** Generated 2026-09-05 from `../../3_thinking/` (the_bet, the_campaign, evidence_synthesis_v1, hypotheses, decision_log, rejected_alternatives) and `../../2_research/` (numbers, community, prospects). Those files remain the source of truth; this page is the readable assembly of them, not a separate record.

**Regenerating.** If a source file changes, update this page rather than letting the two drift — every claim here traces back to a file in `2_research/` or `3_thinking/`.
