# Keyword search demand (Semrush pull, 2026-09-05)

Quantitative Google-search confirmation of the qualitative research read — not a new source.

**The literal category term is dead on Google.** "agent registry" 140/mo, "ai agent registry" 50/mo, "agent skill registry" 10/mo, "skill registry" 40/mo, "aws agent registry" 110/mo (despite AWS's own Aug 31 2026 GA), "share claude code skills" 10/mo. Nobody searches the category name any vendor uses — the pain surfaces in GitHub issues and forum threads, not search bars.

**Where real demand sits (US/mo):** "claude code skills" 8,100 (CPC $5.26, transactional) · "claude skills marketplace" 2,900 (CPC $7.84, climbing hard) · "anthropic skills" 3,600 · "claude skills" 27,100 · "agent skills" 4,400 · "context engineering" 3,600 (one of the fastest-climbing terms in the whole pull) · "mcp registry" 1,600 (traces to Anthropic's own MCP-foundation launch, not organic pull).

**Developer query language is procedural, not category-based** — "how to add skills to claude code" 320/mo, "how to create custom skills for claude code" 170, "how to use skills in claude code" 140 — all how-to/what-is, long-tail, low competition. Unclaimed SEO territory.

**High-intent enterprise language exists but is expensive and CDO-flavored** (matches Atlan's existing top-down motion, not the bottom-up ask): "ai agent security" 880/mo at $28.21 CPC, "ai agent governance" 320/mo at $15.79 CPC.

**How to apply:** this doesn't change the channel bet — GitHub issues and r/claudeskills stay highest-precision. It's a secondary, additive channel: a public SEO-facing asset (a "State of Claude Code Skills" page, or a lightweight skills directory) targeting the how-to long tail would capture real, growing, currently-unclaimed traffic. Risk to flag: Anthropic itself is now shipping the plugin marketplace and MCP registry — the exact surfaces a category called "agent registry" would otherwise own — so the wedge needs to keep leaning on the evidence layer (usage/traces/governance), not on being "the place you get skills."
